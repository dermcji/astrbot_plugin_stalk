# 群友视奸（astrbot_plugin_stalk）

盯住指定的群友。**他隔一阵子第一次出现在群里**时，机器人 @ 他说句话，或者连戳他几下。

不是「一说话就有反应」——那样太吵。等的是「久别重逢」。

## 安装

1. 把 zip 上传到 AstrBot 插件管理里装，或者解压到 `data/plugins/astrbot_plugin_stalk/`
2. 装完在面板里打开插件（默认就是开的）
3. 在 QQ 里发 `/视奸 加 <他的QQ号>`

没有第三方依赖，纯标准库。

## 它到底在等什么

1. 他每次在群里说话，插件记下时间（落盘，重启不丢）；
2. 这次的说话时间距离上一次超过 `stalk_gap_minutes`（默认 **120 分钟**），才算「重新出现」；
3. 这时才动手，动完把时间刷成现在——所以他接着说几句不会再触发。

插件刚装好时还没有他的记录，**只记录不动手**，等他下次"久别重逢"才动。这样重装、重启都不会突然刷屏。

## 动手能做什么

`stalk_action` 四选一：

| 值 | 效果 |
|---|---|
| `poke`（默认） | 连戳他 `stalk_poke_times` 下，两下之间隔 `stalk_poke_interval` 秒 |
| `at` | @ 他说一句话 |
| `both` | 先说一句，再连戳 |
| `say` | 不 @，只发一句话 |

「连戳」用的是 OneBot 的 `send_poke`。**这条通道要看你的 NapCat 版本开没开**——先发一句：

```
/戳一下 你的QQ号
```

自己手机抖了说明通；返回「戳不动」就是 NapCat 不支持，把动作改成 `at` 或 `say`。

## 那句话说什么

- `stalk_lines` 里写几句（每行一句，可以写 `{name}` 换成他的群名片），随机挑一句；
- 留空就让机器人**按你配的人格现编**——它知道对方多久没说话了、刚才说了什么；
- 没有可用模型时用内置的几句口语兜底，不会哑掉。

> **注意**：`stalk_lines` 只在 `stalk_action` 是 `at` / `both` / `say` 时才会用到。
> 停在默认的 `poke` 模式（纯连戳）时它不起作用——那个模式根本不发话。

### 现成台词（可直接抄）

复制进 `stalk_lines`，每行一句，`{name}` 会换成对方的群名片。

**抓包型**——把"我看见你了"说出来：

```
抓到你了 {name}，别以为我没看见
哟，{name}，还活着呢
{name} 出现了，全体注意
咦 {name}，你这号还没注销啊
{name}，几百年没见你冒泡了
```

**装熟惦记型**——装得像真的一直在等他：

```
{name} 你终于来了，我等你好久了
好久没见 {name} 说话了，跑哪去了
{name}，你是不是把我忘了
几天不见，{name} 都变陌生了
{name} 一出现，这群里就有生气了
```

**撒娇粘人型**——贴合二次元人设：

```
主人 {name} 终于回来了，我一直在等
{name} 一消失我这边就冷清了
你不说话的时候我都在数秒，{name}
{name} 再不出现，我就要去翻你主页了
等了你这么久，{name} 一句解释都没有吗
```

**毒舌调侃型**——熟人之间才这么说话：

```
{name} 潜水这么久，肺活量不错啊
稀客，{name} 还记得这个群呢
{name} 你这一冒泡，我都以为号被盗了
来了？{name}，把这几天的账结一下
{name} 舍得出来了，我以为你搬走了
```

**关心型**——换个温度：

```
{name} 忙完了？这几天是不是很累
好久没动静，{name} 没事就好
{name} 你可算冒头了，我还以为出什么事了
{name} 这阵子是不是在忙，注意休息
```

**短句型**——一两个词，干净，适合 `say`：

```
逮到了
活的
终于肯出来了
别潜了
这不是还没退群嘛
```

混着用最好：全填"抓包型"会像复读机，五种各挑两三条，随机起来才像活人。

## 只在群里、只对指定的人

- 只监听群聊，私聊不生效（「隔一段时间没说话」在私聊里没意义）；
- `stalk_groups` 填群号可以限定只在某些群生效，留空是所有群；
- 他自己发 `/` 开头的指令、或者 @ 了机器人时**跳过**，免得跟正常对话打架。

## 指令

| 指令 | 作用 |
|---|---|
| `/视奸` | 看现在盯着谁、各自多久没说话了、还差多久到点 |
| `/视奸 加 123456789` | 盯上这个人（存进 `data/stalk.json`，立刻生效） |
| `/视奸 减 123456789` | 不盯了 |
| `/视奸 清` | 全清 |
| `/戳一下 123456789` | 手动戳一下，确认通道通不通 |

`/视奸` 的输出长这样：

```
视奸开关：开
盯着 1 个人，隔 120 分钟没说就算「重新出现」，动作：连戳 3 下
· 123456789 @群 987654321：上次说话 10-28 20:03（3 小时 12 分前），已经够久，下次冒泡就动手

用法：/视奸 加 <QQ号>　/视奸 减 <QQ号>　/视奸 清
```

## 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `stalk_enabled` | `true` | 总开关 |
| `stalk_qq` | `[]` | 盯着谁，和 QQ 里加的合并去重 |
| `stalk_gap_minutes` | `120` | 多久没说话才算重新出现 |
| `stalk_action` | `poke` | `poke` / `at` / `both` / `say` |
| `stalk_poke_times` | `3` | 连戳几下 |
| `stalk_poke_interval` | `0.8` | 两下之间隔几秒 |
| `stalk_lines` | `[]` | 台词池，留空走模型 |
| `stalk_groups` | `[]` | 只在哪些群生效 |
| `allowed_qq` | `[]` | 谁能用 `/视奸` 指令 |
| `allowed_groups` | `[]` | 哪些群能用指令 |

## 已知限制

- 只有 QQ（aiocqhttp / NapCat）能戳一戳，别的平台退回发文字。
- 只认群消息。想看"进群"事件得等 AstrBot 那边支持群成员变动钩子。
- 同一个 QQ 在不同群里独立计时（记的是「群号:QQ号」）。
- 数据存在 `data/plugin_data/astrbot_plugin_stalk/stalk.json`，只留最近一周的发言时间。
